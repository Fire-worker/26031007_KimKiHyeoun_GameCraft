### 사운드

- 대장간 배경 사운드 ([forge_ambience.wav](audio/forge_ambience.wav) / 24초 반복 재생)
- 씬 전환 효과음 ([scene_transition.wav](audio/scene_transition.wav) / pause.wav 사용)
- 강화 시도 효과음 ([attempt_three_hits.wav](audio/attempt_three_hits.wav) / 세 번째 효과음을 3번 재생)
- 강화 성공 효과음 ([success.wav](audio/success.wav) / 01_parry.wav 직후 relic_aquired.wav를 1.5배속으로 재생)
- 강화 실패 효과음 ([failure.wav](audio/failure.wav) / Torch Attack Strike 2.ogg 사용)

효과음의 음량을 같은 기준으로 맞추고, 게임의 효과음 재생 음량은 70%로 설정한다.

시작 화면과 메인 게임 화면을 오갈 때 씬 전환 효과음을 사용한다. 메인 화면에서는 대장간 배경 사운드가 반복 재생되며, 망치를 클릭하면 3회 타격음이 나온다. 성공과 실패 효과음은 이후 강화 판정 구현 시 사용하도록 보관한다.

강화 시도 효과음은 타격음이 끝난 뒤 0.35초씩 뜸을 들여 총 3번 들리도록 준비하였다. 성공 효과음은 두 소리가 순서대로 이어지도록 준비하였으며, 보상음의 1.5배속이 이미 적용되어 있다.

원본은 `audio/originals`에 보관한다. 개별 가공 파일인 `hammer_hit.wav`, `success_impact.wav`, `success_reward.wav`도 `audio`에 함께 보관한다. 효과음은 약 -20 LUFS로 맞추었으며, 배경 사운드는 효과음보다 작게 들리도록 약 -30 LUFS로 제작하였다. 70% 음량은 게임에서 한 번 적용한다.

## 출처 및 이용 조건

- OpenAI imagegen으로 본 프로젝트용 이미지를 생성하였다.
- 생성한 대장간 배경과 기본 검을 나머지 이미지의 참고 자료로 사용하였다.
- 외부 게임에서 추출한 이미지나 다운로드한 이미지 팩은 사용하지 않았다.
- 이용 조건은 생성에 사용한 OpenAI 서비스의 적용 약관을 따른다. 별도의 CC 또는 퍼블릭 도메인 표시는 하지 않는다.
- 효과음은 기존 프로젝트에서 제공한 파일을 사용하였다. 원본을 보관하고, 게임에 사용할 파일의 음량과 재생 속도를 조정하였다.

- 단계별 검은 기존 검을 참고하여 OpenAI imagegen으로 각각 생성한 뒤, 투명 배경을 유지해 같은 크기로 맞추었다.
- 대장간 배경 사운드는 외부 음원 없이 불과 풀무를 표현하는 소리를 직접 합성하였다.

## 폴더 구성

- `images` : 배경, 모루, 망치와 기존 이미지
- `images/swords` : +0부터 +10까지 단계별 검 이미지
- `audio` : 게임에서 사용할 WAV 파일
- `audio/originals` : 제공받은 원본 음원
- 검 이미지 모음은 `docs/images/sword_levels.png`에 보관한다.

## 적용 범위

- 시작 씬과 메인 게임 씬에서 서로 다른 배경을 출력한다.
- 시작 화면의 게임 시작 버튼 또는 Enter로 메인 게임 화면에 진입한다.
- 메인 화면의 시작 화면 버튼 또는 Esc로 시작 화면에 돌아온다.
- 시작 화면의 종료 버튼으로 프로그램을 종료한다.
- 현재 단계, 남은 시도, 최고 기록은 초기값을 표시하며, 확률은 미정 표시로 둔다.
- 망치 이미지가 강화 버튼 역할을 한다. 마우스를 올리면 15% 커지며, 클릭하면 3회 타격 연출이 나온다.
- 타격 중에는 중복 입력을 막는다. 화면 전환이나 다른 창으로 이동할 때 연출을 초기화한다.
- 강화 판정과 단계 변화, 시도 횟수 차감은 아직 구현하지 않았다.
- 단계별 검 11개를 준비하였으며, 현재 게임에서는 +0 검을 출력한다.
- 캐릭터의 키보드 이동은 구현하지 않는다.
- 씬 전환음, 망치 타격음, 메인 화면의 배경 사운드를 연결하였다. 성공과 실패 효과음은 이후 사용하도록 보관한다.
- 메인 화면을 나가거나 다른 창으로 이동하면 소리를 멈춘다. 메인 게임 창으로 돌아오면 배경 사운드만 다시 재생한다.
- 파괴 조각 이미지는 이후 연출용으로 보관하며, 메인 UI에서는 출력하지 않는다.
- UI의 글자와 패널, 시작·복귀·종료 버튼은 프로그램에서 그린다. 강화 버튼에는 망치 이미지를 사용한다.
